## Status vocabulary

- **SOURCE FIX PRESENT — runtime check pending:** relevant code has been found on `main`; reproduce the user's workflow and confirm the response/state.
- **PARTIAL / BLOCKED:** some code paths exist, but a reported failure or an important precondition remains unverified.
- **OPEN:** a required feature, approved content, configuration or acceptance evidence is still missing.
- **SOURCE-LEVEL FIX CONFIRMED:** the specific unwanted implementation is no longer rendered/used in the checked source; do a quick visual regression check before closing.

## Non-negotiable access rule

**Institution → selected course → that course’s subjects/resources.** Every protected catalogue, lesson, textbook/page/stream, assessment, class, progress and certificate request must be validated server-side against the same resolved institution and the selected course’s active membership/assignment/release/access entitlement. Client headers and URL IDs select context; they are not authorization by themselves. Keep unapproved structured content blocked.
