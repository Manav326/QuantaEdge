# QuantaEdge MVP

Target: Bihar Board Classes 6–8, initially Maths and Science.

## Student
Landing, registration, guardian consent flow, class selection, learning check, today's learning, lesson player, interactive questions, score, progress, basic revision and controlled AI help.

## Parent
Account, child linking, consent, simple progress and weekly learning summary.

## Admin
Curriculum, lessons, questions, student overview and basic analytics.

## Explicitly deferred
Payments/subscriptions, referrals, live classes, teacher marketplace, social feed, voice tutor, native Android, certificates and full-syllabus content production.
